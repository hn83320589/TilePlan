### AC2　300 × 200 → 6.00 m²／1.82 坪；扣 60 × 60 → 5.64 m² — **通過**

### AC3　L 形實測還原，每個頂點誤差 < 0.5 cm — **通過**

- 單元測試：兩組不同的對角線組合誤差為 0；量測值四捨五入到 0.1 cm 時誤差 < 0.5 cm。

- 參考資訊：量測本身帶有誤差時會被放大（±1 mm → 0.86 cm，±2 mm → 2.1 cm）。這是因為 n − 3 條對角線剛好夠用，沒有多餘的量測可以互相校正。
- 對角線穿過牆外時原本會得到錯誤形狀且沒有提示，見發現 F2（已修正）。

### AC4　只有四面牆長時不可假設直角，並說明缺少的量測 — **通過**

- 單元測試：`Rectangle_without_diagonal_is_underdetermined_and_names_the_missing_measurement`、`L_shape_with_one_diagonal_reports_two_missing`、`Out_of_square_room_is_not_forced_to_right_angles`
- 獨立驗證：長方形、L 形、任意四邊形只給牆長，3/3 都拒絕求解。
- 介面（E2）：顯示「缺少 1 條量測，形狀無法唯一決定（只量牆長時，各角的角度未知，不能假設為直角）。建議再量對角線：A–C。」，並提供「加入 A–C」按鈕；排版頁顯示「無法排版」。補上對角線 360.6 後顯示「形狀已解出」（E3）。

### AC7　牆邊切條 ≥ 磚寬 1/3；做不到時顯示原因與實際最小寬度 — **通過**

- 單元測試：長方形對稱且達標；40 個隨機長方形正排全部達標，並以切割片在原磚上的尺寸獨立檢查；交丁 1/3 與斜 3° 的牆回報原因與實際最小寬度。
- 獨立驗證：另外 150 個隨機長方形正排 **150/150 達標**，最窄的切條是門檻的 1.52 倍。交丁 1/2 的達成率是 113/150，做不到的會顯示原因，這是預期行為。
- 介面：範例的 L 形客廳（交丁 1/3）顯示「有 3 面牆的切條小於磚寬的 1/3，實際最小寬度 18.9 cm」（本機與線上 Demo 相同），並逐面牆說明原因，切條不足的牆以紅線標示。

### AC8　200 個以上隨機房間，磚片＋縫 = 可鋪面積，相對誤差 < 0.1% — **通過**

- 性質測試：240 個房間，固定種子 `20261024`。
- 獨立驗證：另外 500 個房間（種子 777、凸多邊形、旋轉的不鋪設區），**最大相對誤差 2.79 × 10⁻⁶**，中位數 3.93 × 10⁻⁷，沒有任何一個超過 0.1%。
- 測試設計：縫面積由磚格另外產生的縫網路計算，沒有用「可鋪面積 − 磚片面積」，因此這個檢查不是恆等式。

### AC9　開啟餘料重用後整片數不增加，且每片重用的餘料確實放得下 — **通過**

- 性質測試：90 個隨機房間。
- 獨立驗證：另外 167 個房間，重用後片數變多 **0 次**、共省下 4,085 片原磚、包含關係違反 **0 次**。

## 11. 依外部審查意見的修正

外部審查指出三個主要問題，處理如下：

| 審查意見 | 修法 | 驗證 |
|---|---|---|
| 量測剛好足夠時殘差必然為 0，畫面卻顯示「最大殘差 0.00 cm」，給人錯誤的信心 | 回報多餘量測數；為 0 時改提示「無法檢查是否量錯」，不顯示殘差。以 Σ = σ²(JᵀJ)⁻¹ 推算各角 95% 不確定範圍（捲尺精度可設定，預設 ±5 mm），並建議一條室內量得到、推算誤差最大的檢核對角線 | `SurveyUncertaintyTests`（5 項，含 2,000 次蒙地卡羅）、`SurveyFormTests`（bUnit，畫面不出現「0.00 cm」）、E2E `Survey_without_redundant_measurements_does_not_claim_zero_residual` |
| 不鋪設區邊緣的碎片沒有檢查（廚具前緣最顯眼） | 不鋪設區露在室內的邊納入偏移最佳化與報告，可個別關閉、預設開啟；另以旋轉卡尺標出所有細碎片 | `ExclusionEdgeTests`（櫃子上緣 5.2 cm 細條手算等 5 項）、`SmallPieceTests`（7 項） |
| 缺少 LICENSE；瀏覽器端對端測試沒有放進 CI | 加上 MIT 授權；新增 Playwright for .NET 端對端測試專案（5 項），CI 另開 `e2e` job | GitHub Actions `e2e` job 成功 |
